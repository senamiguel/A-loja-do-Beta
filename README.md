# A Loja do Beta - E-commerce de Peixes Ornamentais 🐠

## 📝 Descrição do Produto
[cite_start]Este projeto consiste no desenvolvimento de um site comercial ("A Loja do Beta") especializado na venda de peixes ornamentais para aquários. O objetivo é oferecer uma plataforma intuitiva para aquaristas visualizarem catálogo, detalhes de espécies e realizarem a simulação de compra.

O trabalho foi desenvolvido como requisito final da disciplina de **Desenvolvimento de Aplicação Web Front-End (CC2N)** da Dom Helder, sob orientação da professora Flávia Martins.

## 🚀 Tecnologias Utilizadas
[cite_start]O projeto foi construído utilizando as seguintes tecnologias e frameworks[cite: 51]:

* **HTML5** (Semântico e Acessível)
* **CSS3** (Estilização personalizada)
* **Bootstrap** (Framework CSS para responsividade e layout)
* **JavaScript (ES6+)** (Interatividade, manipulação do DOM e validação de formulários)

## 🔧 Instruções para Execução Local
[cite_start]Para rodar o projeto em sua máquina local, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/senamiguel/A-loja-do-Beta.git](https://github.com/senamiguel/A-loja-do-Beta.git)
    ```
2.  **Acesse a pasta do projeto:**
    ```bash
    cd A-loja-do-beta
    ```
3.  **Abra o projeto:**
    * Navegue até a pasta e dê um duplo clique no arquivo `index.html`.
    * Ou, se estiver usando o VS Code, utilize a extensão **Live Server** para abrir o `index.html`.
